# Changelog

## [Unreleased]

### Added
- Light, dark and system themes across the popup, sidebar, options and welcome pages. Changing the theme in Options applies instantly everywhere.
- Settings button in the popup that opens the Options page.

### Changed
- Notifications are now turned on or off only from the Options page. The toggle was removed from the popup.
- The popup now uses the system UI font.

### Fixed
- Notifications were sent for every prayer instead of only the prayers selected in Options.

## [1.2.1]

### Fixed
- The remaining time for the next prayer wasn't displaying correctly.
- Notifications are now disabled by default.

### Improved
- The countdown now shows remaining seconds.
- New "Back to Top" button in the sidebar.

## [1.2.0]

### Added
- **Prayer times sidebar:** a full view of all prayer times with the upcoming prayer highlighted.
- **Morning and evening adhkar:** the complete collection, a counter for each zekr, a reset button, and the virtue (fadl) of each one.
